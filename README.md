# XAU/USD Market Dashboard V5.1

Dashboard តាមដានទីផ្សារ Gold (XAU/USD) ដែលមាន TradingView Live Chart និងឧបករណ៍វិភាគបច្ចេកទេស។

## មុខងារសំខាន់ៗ

- TradingView Live XAU/USD chart
- Candlestick chart និង EMA
- RSI, MACD និង ATR
- Supply & Demand zones
- Technical / AI Hybrid signal summary
- Entry, Stop Loss និង Take Profit levels
- Buyers / Sellers pressure estimate
- Gold volume និង USD pressure proxy
- Capital / Risk calculator
- Customizable chart appearance និង settings

## តម្រូវការ

- Internet connection
- Twelve Data API key សម្រាប់ទាញ candle data របស់ Dashboard
- TradingView widget ដំណើរការតាមអ៊ីនធឺណិត

**ចំណាំ:** TradingView chart និង Twelve Data អាចបង្ហាញតម្លៃខុសគ្នា ព្រោះប្រើប្រភពទិន្នន័យផ្សេងគ្នា។ សូចនាករ និងសញ្ញាវិភាគគឺជាជំនួយសិក្សា មិនធានាលទ្ធផលទីផ្សារទេ។

## ដាក់ក្នុង GitHub

1. ចូលទៅ https://github.com ហើយ Sign in។
2. ចុច **New repository**។
3. ដាក់ឈ្មោះ Repository ឧទាហរណ៍ `xau-usd-dashboard`។
4. ជ្រើស **Public** ឬ **Private** តាមតម្រូវការ។
5. Upload ឯកសារ `index.html`, `README.md` និង `.gitignore` ទៅ Repository។
6. ចុច **Commit changes**។

## បើកជា Website ដោយ GitHub Pages

1. ចូល Repository របស់អ្នក។
2. ចូល **Settings → Pages**។
3. នៅ **Build and deployment** ជ្រើស **Deploy from a branch**។
4. ជ្រើស Branch `main` និង Folder `/ (root)`។
5. ចុច **Save**។
6. រង់ចាំ GitHub Pages បង្កើត Website រួចបើក URL ដែល GitHub ផ្ដល់ឱ្យ។
